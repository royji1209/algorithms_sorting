BFS(동심원) vs DFS(선형)

BFS는 특정 깊이에 다수의 노드가 모이는 종형 분포를, DFS는 좁고 깊게 퍼지는 분포를 형성합니다.

Frontier Nodes

BFS는 층별 탐색으로 큐 크기가 증가(O(V))하며, DFS는 경로 분기점만큼만 스택(O(H))을 점유합니다.
