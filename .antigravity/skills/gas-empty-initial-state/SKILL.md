# GAS 웹앱 초기 빈 상태(Empty State) 강제 규칙

Google Apps Script(GAS) 웹앱을 생성하거나 수정할 때 첫 화면(초기 로딩 상태)에 어떠한 기본값·더미·샘플·목업 데이터도 삽입하지 않는다.

## 필수 지침

1. **초기 빈 상태 유지**: 첫 렌더링 시 입력 필드, 테이블, 목록, 카드, 차트 영역은 빈 상태 또는 초기화 상태로 시작한다.
2. **하드코딩 금지**: 프론트엔드(`index.html` 등)와 백엔드(`Code.gs` 등)에 테스트용 예시 데이터, 임의 기본 텍스트, 가상 레코드, 자동 시드(seed) 로직을 작성하지 않는다.
3. **안내 문구 제공**: 표시할 데이터가 없을 때는 `"데이터가 없습니다"` 또는 `"입력/조회 후 결과가 표시됩니다"` 같은 안내 문구와 빈 상태 UI만 렌더링한다.
4. **명시적 트리거 기반 반영**: 사용자가 직접 입력하거나 버튼을 클릭하거나 실제 저장된 데이터 조회를 요청할 때만 데이터를 반영한다.
5. **빈 응답 처리**: `google.script.run` 호출 결과나 외부 연동(`PropertiesService`, 시트, API 등) 결과가 빈 배열(`[]`), `null`, 빈 객체(`{}`) 또는 빈 값일 때 임의의 대체·기본 데이터로 채우지 않고 빈 상태를 유지한다.
6. **기존 코드 리팩토링 시**: 이미 샘플·더미 데이터가 포함된 코드를 수정할 때는 해당 데이터를 제거하고 초기 상태를 빈 값으로 정리한다.
